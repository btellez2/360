# CS 360
1. App Requirements and Goals

For this project, I developed an event-tracking application using Android Studio. The goal was to help users organize their events, keep track of important dates, and manage their schedules.

2. UI Design and Features

I designed a login screen and an event management screen. I focused on making the application simple, organized, and easy to navigate. I used clear buttons, labels, and input fields to improve the user experience.

3. Coding Process

I developed the application using Java and XML in Android Studio. I worked on one feature at a time and kept my project files organized. This approach helped me troubleshoot errors and understand how different components work together.

4. Testing

I used the Android Emulator to test the application’s layout and functionality. I checked the screens and navigation to identify errors and make improvements. Testing helped me understand the importance of making sure an application works correctly.

5. Challenges

One challenge was connecting the user interface to the application code. I overcame this by reviewing my code, fixing errors, and testing each component individually.

6. Skills and Experience

I am most proud of creating the event management screen. This project helped me improve my skills in Android Studio, Java, XML, and mobile application development.

Final Reflection

Overall, this project taught me how to design, develop, and test a mobile application. I gained valuable experience that I can apply to future software development projects.
